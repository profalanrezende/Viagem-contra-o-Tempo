# Viagem contra o Tempo — A.R.S. HTML APPS e GAMES

Cálculo mental para alunos do 1º ao 3º ano: uma viagem pelo Sistema Solar contra o relógio.

## Mundos (27 fases, 3 por mundo)
Terra → Marte → Júpiter → Saturno → Urano → Netuno → Mercúrio → Vênus → **Galáxia Mágica (Nível Expert: mais, menos, vezes e dividido, tabuada até 10)**.
Mais e menos vão de somas até 5 até centenas e dezenas (só nos últimos mundos).

## Missão Estrela ∞
Ao vencer um mundo (3 fases com ao menos 1 estrela) libera-se a missão ⭐ com contas daquele mundo: 1m30 no relógio, +10 s a cada acerto e −10 s a cada erro, até o tempo acabar. Guarda o recorde de contas. A Galáxia Mágica não tem estrela.

## Regras
Meta de acertos antes do relógio zerar; acerto devolve tempo, erro tira 2 s. 3 estrelas = até 1 erro (dica conta meio erro).
